# Negotiated original action authorization

HAPI #397 supplies the SDK source-v2 metadata variant selected by `actionMetadataVersion: 1`.
The existing plugin getter context adds the frozen `sourceCapabilities` list. A projection can
require `original-action-authorization-v1` through `requiredSourceCapabilities`; unknown, absent
or malformed requirements fail before creating its owner. The selected immutable metadata mode
passes from the registry through the actual worker controller into original source capture.
The producer rejects malformed selection before raw admission. Existing declarations without a
requirement keep metadata off, including the old strict source fields and digest coordinates.

`deriveProtocolActionOccurrences` validates the complete retained trace's ordered actor/permission
records. The source decoder copies those original fields beside decoded `data`, binds them into
the source-evidence coordinate and SDK source/candidate digest, and keeps all existing original
capture, ABI/native action, canonical, owner/fork and cancellation checks. The action-data payload
hash alone does not authenticate authorization. The host never accepts a plugin-supplied list
or places authorization into contract data. Tables never acquire authorization fields. Explicit
empty original lists remain empty; missing metadata does not become an empty list.

The root SDK and native MongoDB adapter's own SDK dependency/lock must both select the reviewed
SDK implementation. The receiver recaptures its declaration and fixed candidate through its own
actual SDK imports. Updating only the caller cannot make an old receiver accept the new variant.
Installed package paths and native host/adapter command-fixture controls are implementation
compatibility evidence, not physical MongoDB/Wire, HTTP parity or production qualification.

New requiring plugins reject old host contexts immediately because earlier hosts ignored unknown
projection requirement fields. Compatibility with the genuine old f450 Atomic packaged getter
is tested separately using its hash-bound installed artifact; an arbitrary stub is insufficient.
No v1 capture, owner/storage namespace, recovery budget or serving grant changes in this slice.
A compatible new plugin declaration/generation and qualified replay remain activation gates.
